# E11 Notation Glossary

This generated glossary fixes the notation used across the E11 paper-facing artifacts. It should be treated as the source of truth for symbols in figure captions, discussion text, and the final report.

## Symbols

| symbol                            | definition                                                                                                                                                                                                                            | scope                                                                                                                                 |
|:----------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------|
| \(W_i\)                           | The trainable matrix parameter at layer or factor \(i\).                                                                                                                                                                              | All matrix-parameter problems.                                                                                                        |
| \(G_i = \nabla_{W_i} L\)          | The gradient matrix of the loss with respect to \(W_i\) at the current step.                                                                                                                                                          | All diagnostics and one-step analyses.                                                                                                |
| \(\Delta W_i\)                    | The signed parameter change \(W_i^+ - W_i\) after one optimizer step.                                                                                                                                                                 | Adam, Muon, stateless controls, and update-spectrum diagnostics.                                                                      |
| \(D_i=-\Delta W_i=W_i-W_i^+\)     | The positive descent update convention used by `update_grad_inner` and update-spectrum diagnostics.                                                                                                                                   | One-step decrease calibration, boundary comparisons, and theory note.                                                                 |
| \(\langle G_i, D_i\rangle\)       | The positive first-order decrease proxy for layer \(i\), equal to \(-\langle G_i,\Delta W_i\rangle\).                                                                                                                                 | One-step decrease calibration and boundary comparisons.                                                                               |
| \(\Delta L\)                      | Observed one-step loss decrease, recorded as loss before the optimizer step minus loss after that step on the same training batch.                                                                                                    | Step metrics and first-order calibration.                                                                                             |
| \(nr(M)=\|M\|_*^2/\|M\|_F^2\)     | Numerical rank / nuclear-rank diagnostic used for gradients and updates.                                                                                                                                                              | `nrG`, `nrUpdate`, and normalized rank-fraction plots.                                                                                |
| \(sr(M)=\|M\|_F^2/\|M\|_{op}^2\)  | Stable-rank diagnostic used for activation/product matrices and updates.                                                                                                                                                              | `stA`, `stUpdate`, and condition-score diagnostics.                                                                                   |
| \(A_i\)                           | Problem-specific activation/product matrix paired with \(G_i\). In MF-with-input, \(A_i=W_{i+1}\cdots W_{10}Z\), with \(A_{10}=Z\). For MLPs, \(A_i\) is computed from the full dataset even when training uses a smaller mini-batch. | Strict activation-product interpretation only in MF-with-input; other tasks use problem-specific full-diagnostic spectral quantities. |
| \(C_i=nr(G_i)/sr(A_i)\)           | Layerwise condition score used in the original condition-geometry plots.                                                                                                                                                              | Condition-score diagnostics, not the final main mechanism claim by itself.                                                            |
| `nrUpdate`, `stUpdate`            | Numerical-rank and stable-rank diagnostics computed from the singular values of \(D_i\), equivalently \(\Delta W_i\).                                                                                                                 | Main update-spectrum signature.                                                                                                       |
| \(D_F^\star=rG/\|G\|_F\)          | The locally optimal positive descent update under a Frobenius update budget.                                                                                                                                                          | Theory note and spectral-allocation probe.                                                                                            |
| \(D_{op}^\star=\eta U_qV_q^\top\) | A locally optimal positive descent update under an operator-norm update budget.                                                                                                                                                       | Theory note and spectral-allocation probe.                                                                                            |

## Recorded Diagnostics

| quantity            | meaning                                                                                                                | interpretation_rule                                                                               |
|:--------------------|:-----------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------|
| `loss`              | Objective value at the recorded step.                                                                                  | Lower is better for optimization, but loss alone does not identify the mechanism.                 |
| `recovery_error`    | Problem-specific normalized reconstruction/recovery error when defined.                                                | Use as performance context, not as the primary geometry metric.                                   |
| `update_grad_inner` | Positive first-order decrease proxy, equal to \(\sum_i \langle G_i,D_i\rangle=-\sum_i \langle G_i,\Delta W_i\rangle\). | At matched update size, larger values mean better local one-step alignment.                       |
| `delta_loss`        | Observed one-step loss decrease on the same training batch used for the gradient/update.                               | Compare with `update_grad_inner` to test local first-order calibration.                           |
| `condition_score`   | Aggregated form of \(nr(G_i)/sr(A_i)\).                                                                                | Useful exploratory geometry, but not sufficient to claim progress without loss/decrease evidence. |

## Scope Notes

1. The strict activation-product definition of \(A_i\) applies to MF-with-input. Matrix Sensing and MLP diagnostics still report an \(A_i\)-like spectral quantity, but those are task-specific diagnostics rather than the same theoretical object.
2. MLP training uses a strict mini-batch (`train_batch_size < num_samples`), while MLP activation diagnostics use the full sampled dataset for that problem instance.
3. `delta_loss` is a same-batch pre/post-update quantity, not the difference between losses evaluated on two independently sampled training batches.
4. The main paper claim is about update-spectrum shaping through the descent update \(D_i\), not about condition score alone.
5. Higher \(nr\) or \(sr\) should not be read as better optimization without the one-step decrease or performance evidence tied to it.
